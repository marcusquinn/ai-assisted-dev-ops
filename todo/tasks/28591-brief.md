# Issue #28591: Add corpus catalog and authorization foundations

## Origin

- **Issue:** #28591
- **Parent:** #28587 / `t18176`
- **Created by:** ai-interactive
- **Tier:** `tier:thinking`

## What

Add a private schema-v1 SQLite corpus catalog to personal knowledge mode,
register the unchanged `_knowledge` tree as `personal:default`, and resolve it
only through an owner-only local principal context plus active membership and
capability grants.

## Constraints

- Keep `repos.json` modes `off|repo|personal` unchanged.
- Do not move or rewrite existing personal knowledge.
- Never accept a caller-provided principal or authorize from a corpus ID alone.
- Require active principal, workspace, membership, corpus, and explicit grant.
- Reject malformed, symlinked, wrong-owner, or group/world-readable context and
  any resolved location outside the configured personal base.
